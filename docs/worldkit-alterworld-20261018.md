# 异次元世界方案（调研，2026-10-18）

三立场独立方案后由主控收敛。未实现、未进题库。探针，不进 `ACTIVE_ITEMS`。

目标：在现有 worldkit 上测**反直觉规则下的长程推理**和**指令遵循**（题面规则优先于地球常识）。

## 推荐

第一刀只做一个充电形状的新题族（暂名 `vat` 双釜），物理符号与 `dual_progress` 相反，再加一条仍与半格交织的「霜缩」。不写法律/道德倒置。生成时加一张「地球消融卷」：用地球内核算出的答案对异次元冻结分必须是 0。

| 立场 | 一句话 |
|---|---|
| 最简 | 复用充电的排列 + 两口釜；谐振（同时做变快）+ 霜缩（做到一半体积变小）；不改 `share.py` |
| 风险 | 最大洞是地球整数碰巧得分；禁止犯罪/守法题；反事实不得删半格；先抽三道，出现 0 或满分就停 |
| 演进 | 物理钉在「宇宙版本 × 决策形状 × 场景数据」，禁止十五景那种同一套 simulate 换皮；遵循/推理分栏且没有合成总分 |

## 成立的攻击

- 最简只做一题、四问仍 6/5/4/5：风险指出 exact 不绑方案，地球启发式仍可能拿 4 分。必须加地球消融卷拒收。
- 演进要新的宇宙/形状登记和分栏 schema：对第一刀过重。第一刀先用现有四问 + 地球对照标签，分栏放到第二刀。
- 风险清单里的积热/串扰/预热四条一起上：最简认为两条模块才撑得起「反事实还难」。第一刀只开谐振 + 霜缩。
- 「保护犯罪」没有可重放状态，会变成拒答或猜作者。三方一致：不做。

## 第一刀合同

- 决策：6～7 个批次的排列，投更早空闲的釜（与充电相同）。
- 谐振：两釜都忙则每分钟 +2 单位；单釜则半格，满 2 才 +1，伙伴空闲半格清零。
- 霜缩：指定分钟对已开工且完成 ≥1 的批次削减剩余（至少留 1）。反事实只平移这个分钟，谐振仍在。
- 题面声明全部规则和来源（管路谐振、霜使未完成体积缩小），答错代价是船期。
- 猎题：`band.accept`，贪心 4–8 分；另测同一排列用 `dual_progress` 重放对不上冻结值。
- 对照：地球消融卷对冻结答案 0 分，否则整题丢弃。
- 三道实网抽测，出现超时 0 或 ≥15 或「只对反事实」则停题族。

## 明确不做

道德/法律价值题；十五景换皮；改 `dual_progress` 加开关（会牵动充电/后厨/床位）；LLM 判分；按模型自己的方案重算 exact；进活跃题库。
