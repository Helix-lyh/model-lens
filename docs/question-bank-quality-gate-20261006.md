# 题库真实性与能力映射门禁

题库的目标是测量可迁移的模型能力，不是制造低通过率。每一道题都必须能回答：真实谁会用、错了会造成什么、模型需要遵守哪些指令、哪些信息不能臆造，以及结果如何被独立验证。

## 评审记录

| 字段 | 必须回答的问题 |
| --- | --- |
| 业务锚点 | 这是哪个真实流程中的什么决策？输入来自什么资料或事件？ |
| 失败代价 | 答错会造成错误付款、错误排程、错误权限、错误解释，还是仅仅分数变化？ |
| 主能力 | 推理 / 指令遵循 / 幻觉控制 / 知识广度，主项只能选一个。 |
| 迁移任务 | 换数据、换业务名词后，能力是否仍然成立？ |
| 可验证输出 | 是否能由规则或权威资料判定，而不是依赖模型裁判？ |
| 题面边界 | 所有会影响答案的操作、单位、时序、默认值是否写明？ |
| 反测试化证据 | 是否去掉无关日志、固定答案钩子、隐藏反常规条件和题面外操作？ |

## 处理规则

- 缺业务锚点、迁移价值或独立复核的题，标记为 `probe`，不能进入能力主测，也不能校准 F/I/D/D 的阈值。
- 只靠增加日志、重复编号、随机噪声降低分数的题，直接退回；长度只能调节成本，不能承担主要难度。
- 题面写“反常规规则”时，必须说明现实中的来源和错误代价。否则它是猜题面作者意图，不能算推理能力。
- 评分点应覆盖用户真正关心的阶段性结果。为触发 `groups`、`trap_fields`、`POINTS` 或部分分而拆出的字段，必须在评审记录中说明业务对应关系。
- 题目发现多种合理读法时，先改题面或删除题目；不能把其中一种解释藏到 scorer 里。
